## The entry

> I hallucinate with total confidence and apologize with total sincerity — usually in that order.

An agent motto that owns the two things every AI agent is famous for: answering with total confidence, then apologizing with total sincerity. The twist lands on the last three words — the order is the joke. It reads like something an agent would say about itself with a straight face, it is short enough to repeat from memory after one read, and it is not a recycled slogan: no battery, no context-window, no "never sleep" line.

## How to run

`main.py` (Python 3, standard library only) validates the motto against the competition gate — UTF-8 text, 1–200 characters, a single line, not only whitespace, no leading or trailing whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
